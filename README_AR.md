# ثيم Lumia لمنصة سلة — Twilight

هذه الحزمة هي تحويل لواجهة مشروع Lumia المحدث من React/Vite إلى ثيم **Salla Twilight**.

## ما يعمل من سلة فعلياً
- المنتجات والأسعار والمخزون وخيارات اللون/الباقة.
- زر الإضافة إلى السلة، كوبونات الخصم، الشحن، الدفع وإتمام الطلب.
- تقييمات المنتج الحقيقية عبر مكوّن `salla-comments`.
- المفضلة والبحث وصفحة السلة وصفحات الحساب الأساسية.

## قبل النشر
1. افتح `twilight.json` واستبدل رابط GitHub وبريد الدعم ورابط الدعم ببياناتك.
2. من إعدادات الثيم في سلة اجعل اللون الرئيسي `#df6d90`.
3. أنشئ منتج لانا في لوحة سلة وارفع صوره الحقيقية وخياراته وأسعاره ومخزونه.
4. راجع نصوص الضمان والشحن والتنبيه الصحي.
5. حُذفت جميع بيانات المعاينة التجريبية من هذه النسخة؛ تقييمات العملاء والمخزون والمبيعات تُعرض من بيانات سلة الفعلية.

## التطوير المحلي
```bash
npm install
npm run development
# ثم من Salla CLI
salla theme preview
```

راجع `PUBLISH_SALLA_AR.md` و`PRODUCT_SETUP_AR.md` قبل الربط بالحساب.


## إصلاح التوافق
راجع `VALIDATION_REPORT_AR.md` لمعرفة إصلاحات الإصدار 1.1.1 وخطوات الرفع الصحيحة.
